How is model inference different from supervised model training using labeled data?
Model inference and supervised model training differ mainly in purpose and process:

1. **Purpose**:  
- **Training**: To learn patterns from labeled data by adjusting model parameters.  
- **Inference**: To apply the trained model to new, unseen data to make predictions or decisions.

2. **Process**:  
- **Training**: Involves feeding input data with corresponding labels, computing loss, and updating model weights through optimization (e.g., backpropagation).  
- **Inference**: Uses the fixed, trained model parameters to generate outputs from input data without changing model weights (no backpropagation).

In short, training builds the model using labeled data; inference uses the trained model to predict on new data.
